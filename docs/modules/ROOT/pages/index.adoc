== Installation

To use this extension, add the `io.quarkiverse.jdbc:quarkus-jdbc-db2` dependency to your build file.

With Maven, add the following to your `pom.xml`:

[source,xml,subs=attributes+]
----
<dependency>
    <groupId>io.quarkiverse.jdbc</groupId>
    <artifactId>quarkus-jdbc-db2</artifactId>
    <version>{project-version}</version>
</dependency>
----

With Gradle, add the following to your `build.gradle`:

[source,gradle,subs=attributes+]
----
implementation("io.quarkiverse.jdbc:quarkus-jdbc-db2:{project-version}")
----
